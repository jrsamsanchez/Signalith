{{- $full := include "signalith.fullname" . -}}
{{- $ns := .Release.Namespace -}}
Signalith is starting{{ if .Values.opensearch.enabled }} with its own OpenSearch{{ end }}. The first start takes a few minutes:

  kubectl -n {{ $ns }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -w

1. Show the first admin password (sign in as admin):

  kubectl -n {{ $ns }} get secret {{ $full }}-secrets -o jsonpath='{.data.initial-admin-password}' | base64 -d; echo

2. Open Signalith:
{{- if eq .Values.server.service.type "LoadBalancer" }}

  kubectl -n {{ $ns }} get service {{ $full }}   # its EXTERNAL-IP, port {{ .Values.server.port }}
{{- else if eq .Values.server.service.type "NodePort" }}

  kubectl -n {{ $ns }} get service {{ $full }}   # any node's address, at the node port shown
{{- else }}

  kubectl -n {{ $ns }} port-forward service/{{ $full }} {{ .Values.server.port }}:{{ .Values.server.port }}
  # then https://localhost:{{ .Values.server.port }}
{{- end }}

  The browser warns about the certificate until you trust Signalith's CA:
  "Download the server certificate" on the sign-in page (docs/https.md).
{{- if not .Values.server.publicURL }}

Agents outside the cluster need Signalith's address: set server.publicURL
to the address they reach it at, then helm upgrade.
{{- end }}

Guide: https://signalith.io/docs/kubernetes/
