        Disk guard
        
            
        Deletes the oldest event days before OpenSearch’s disk fills up. At 95% OpenSearch makes every index read-only, and new events stop.
        
          
        
          
        
        
        
        
          
        
          
        
            
        
              
        
                
                
        Checks the fullest OpenSearch data disk every 5 minutes.
        
              
        
              
        
            
        
            
        
              
        
                
                
        From 50% to 94%. Above it, the oldest days go first.
        
              
        
              
        %
        
            
        
            
        
              
        
                
                
        The guard never deletes today or these last days.
        
              
        
              
        days

        Servers
        
        
        The Signalith servers that share this OpenSearch. One of them runs the background jobs: detections, threat intel downloads and data retention.
        
      
        
    
        
    
        
  
        

  
  
        
    
        
      
        A query is a search followed by commands joined with |. The search picks events; each command reshapes the results.
        
      

      
        Search
        
      
        
        
        Only events of one data model: Authentication, Endpoint, Network_Traffic, Change, Malware, Other or Risk.
        
        
        A field equals a value. Matching ignores case.
        
        
        Wildcards with *.
        
        
        Comparisons: = != < <= > >=.
        
        
        Any of several values.
        
        
        Text anywhere in the raw event.
        
        
        Terms are ANDed. OR binds tighter, as in SPL. Use NOT and parentheses as needed.
        
        
        Time range. It overrides the time picker.
        
      
        

      
        Commands
        
      
        
        
        Aggregate with count, dc, sum, avg, min and max.
        
        
        A series over time.
        
        
        The most common values, with percentages.
        
        
        Filter rows. Uses AND and OR like most languages.
        
        
        Sort. Put - before a field for descending.
        
        
        Keep the first N rows.
        
        
        Choose the columns.
        
        
        Rename columns.
        
        
        Add owner, priority and category from the asset and identity lists, as dest_owner, user_priority and so on.
        
        
        Keep only events whose IP, domain, URL, hash or email fields match threat intel, with threat_match_value, threat_source and threat_weight columns. Name fields to check only those, as in | threatmatch src, dest. Put it right after the search.
        
        
        Check any result against threat intel. Adds src_intel_source, src_intel_type, src_intel_weight and src_intel_description where a value is a known indicator.
